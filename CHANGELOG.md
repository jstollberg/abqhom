# Changelog

All notable changes to `abqhom` are documented in this file. The project
follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-24

### Added

- Computational homogenization of two- and three-dimensional RVEs containing
  compatible continuum, truss, beam, and shell elements.
- Affine and periodic displacement boundary conditions, including periodic
  rotational constraints for structural elements.
- Variationally consistent reduction of periodically duplicated boundary
  elements and consistently weighted complete-cell analyses.
- Recovery of effective stress and incremental virtual power, together with
  Hill--Mandel residual evaluation.
- CSV and VTK post-processing utilities.
- An isolated runtime installer for using `abqhom`, Gmsh, and Paraqus with
  Abaqus.
- Tutorial and manuscript-reproduction examples, automated tests, and online
  documentation.
