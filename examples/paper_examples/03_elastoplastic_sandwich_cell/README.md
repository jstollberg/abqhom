# Example 3: elastoplastic sandwich cell

This example studies the cyclic effective response and the initial and
evolved yield surfaces of a mixed-dimensional sandwich cell. The cell
contains a soft elastic continuum matrix, two ideally plastic shell skins,
and an embedded ideally plastic BCC beam core.

## Scripts

- `main.py` computes the cyclic effective response, PEEQ histories,
  verification measures, and VTK output.
- `sandwich.py` provides the shared Gmsh geometry definition.
- `yield_surface_stress_driven/` contains the stress-driven yield-surface
  workflow.
- `yield_surface_strain_driven/` contains the strain-driven yield-surface
  workflow.

Both yield-surface directories provide the same two entry points:

- `yield_surface_2d.py` computes the initial and evolved sections in the
  `sigma11-sigma22` and `sigma11-sigma33` planes.
- `yield_surface_3d.py` samples the complete initial or evolved surface in
  normal-stress space using independent resumable workers.

Each workflow additionally contains `yield_surface_common.py`, which provides
the model construction, state preparation, yield detection, and
result-configuration helpers shared by its two samplers. The strain-driven
common module also provides the elastic calibration used to map prescribed
stress-space directions to macroscopic strain paths.

Activate the isolated Abaqus runtime as described in the
[installation guide](https://abqhom.readthedocs.io/en/latest/installation.html).

## Cyclic response

Run the cyclic analysis from this directory:

```console
abaqus cae noGUI=main.py
```

The prescribed axial history contains two fully reversed cycles between
`epsilon_11 = -0.03` and `epsilon_11 = 0.03`, followed by unloading to zero.

## Yield-surface workflows

Enter either `yield_surface_stress_driven/` or
`yield_surface_strain_driven/`. The corresponding two-dimensional sections
are generated with:

```console
abaqus cae noGUI=yield_surface_2d.py
```

The two workflows provide alternative loading controls for sampling effective
yield surfaces. The default configuration samples both planes for the initial
and evolved states with 36 directions per plane. The stress-driven workflow
prescribes effective-stress paths directly. The strain-driven workflow uses
prescribed macroscopic strain paths and an elastic calibration to select
probing directions in effective-stress space. Each workflow applies its
configured operational yield criterion relative to the respective base state
and guards the detected onset with constituent PEEQ output.

Set `selected_state` and `selected_plane` in the final `main(...)` call of each
two-dimensional script. The strain-driven script additionally provides the
`calibration_only` setting. Its three-dimensional sampler requires the
effective stiffness and compliance generated by the two-dimensional script.
Completed section directions are resumed from their CSV files.

Select the initial or evolved surface through `state_name` in the final
`main(...)` call of `yield_surface_3d.py`, then run:

```console
abaqus cae noGUI=yield_surface_3d.py
```

The default single-worker configuration resumes all 642 sampling directions
from its CSV file. After sampling has completed, set `merge_only=True` and run
the same script once more to assemble the ordered surface and its triangular
connectivity. Repeat the procedure with the other `state_name` when both
surfaces are required.

Independent workers can optionally split the sampling. Set the same
`number_of_workers` in separate copies of the script and assign each copy a
different `worker_index` from zero to `number_of_workers - 1`. All workers for
one state must use the same analysis configuration. Run the merge stage only
after every worker has completed.

Configuration records accompany the resumable yield-surface results. Remove
the corresponding result directory before restarting an analysis with
changed material, mesh, loading, or sampling settings.

## Generated output

The cyclic analysis writes:

| Directory | Contents |
|---|---|
| `abq/` | Cyclic Abaqus job |
| `results/` | Effective response, equivalent plastic strain history, and verification measures |
| `vtk_output/` | Cyclic VTK collection |

The cyclic `results/` directory contains:

| File | Contents |
|---|---|
| `cyclic_response.csv` | Pseudo-time, axial strain, nine effective-stress components, stress-asymmetry residual, and Hill–Mandel residual |
| `peeq_history.csv` | Pseudo-time and maximum shell and beam PEEQ |
| `verification_metrics.csv` | Maximum stress asymmetry, Hill–Mandel residual, shell PEEQ, and beam PEEQ |

Each yield-surface workflow writes its data into the directory containing its
scripts:

| Directory | Contents |
|---|---|
| `2d_section_results_initial/` | Initial yield-surface sections and their Abaqus jobs |
| `2d_section_results_evolved/` | Evolved yield-surface sections and their Abaqus jobs |
| `3d_surface_results_initial/` | Initial 3D surface, worker files, and Abaqus jobs |
| `3d_surface_results_evolved/` | Evolved 3D surface, worker files, and Abaqus jobs |

The sectional result directories contain `sigma11_sigma22.csv`,
`sigma11_sigma33.csv`, the common base strain and stress, and the sampling
configuration. Each merged 3D directory contains `yield_surface.csv`,
`directions.csv`, `faces.csv`, the common base state, and the resumable worker
files below `parts/`.

The initial strain-driven section directory additionally contains the
effective stiffness and compliance, their calibration configuration, and the
corresponding Abaqus calibration jobs.
